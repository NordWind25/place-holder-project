# Place Holder Project

API-клиент на Python для работы с сервисом [JSONPlaceholder](https://jsonplaceholder.typicode.com/).

## Описание

Проект предоставляет класс `ApiClient` для отправки HTTP-запросов (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`) с автоматическим логированием, поддержкой сессий `requests.Session` и базовой обработкой исключений.

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/NordWind25/place-holder-project.git
   ```

2. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```
   
## Использование

Для запуска демонстрации всех доступных HTTP-методов выполните:
```bash
python client.py
```
